### Phase 3 — Script and local-artifact review

Inventory scripts across `scripts/`, `local-scripts/`, `tools/`, `marketing/**/scripts/`, `New Campaigns October 2026/**`, and other folders. For each file classify:

- **Keep as maintained tool:** still used, safe, reviewed, parameterized, documented, and free of embedded secrets/PII.

Review for embedded credentials, hard-coded production URLs, unintended write/send side effects, stale target tenant, local machine assumptions, and sensitive artifacts. Do not execute scripts as part of the classification. Add or update ignore rules only after identifying whether ignored data is disposable or operator evidence.
