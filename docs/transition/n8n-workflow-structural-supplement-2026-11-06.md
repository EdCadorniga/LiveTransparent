# n8n-lt workflow structural supplement — 2026-11-06

**Scope and method:** Read-only, paginated `GET /api/v1/workflows?limit=100` against the explicitly verified `n8n-lt` endpoint (`automations.livetransparent.com`); no execution, activation, workflow edit, or node-parameter readback was used for this supplement. The companion [CSV](n8n-workflow-structural-supplement-2026-11-06.csv) was generated from the returned workflow summaries with an explicit output-field allowlist: ID, name (line breaks normalized), active/archived booleans, shared project IDs, workflow setting `timezone`, **credential type names only** (not IDs/names/values), unique node type names, node count, and counts of Webhook and Schedule/Cron trigger nodes. Semicolon-separated list columns are sorted/deduplicated; rows are sorted by ID case-insensitively. The API key was read from the local `.env` into the request header and was not emitted into the artifact.

**Validation:** 212 CSV rows, 212 distinct IDs, exact header schema, and the same ID set as the [November 4 inventory](n8n-workflow-inventory-2026-11-04.md); active `107`, archived `32`, and all 212 node counts and active/archive flags match that earlier snapshot. Trigger counts are bounded by node counts. The 212 rows report 1,490 nodes, including 108 Webhook nodes and 81 Schedule/Cron nodes; these are node counts, **not** proven active paths, external subscriptions, or runtime successes. All rows contain the same shared project ID in the returned API data; this is not proof of project membership or access policy outside that API response. A bounded text scan found no PIT/key/bearer/password assignment patterns in the CSV; structural fields can still reveal internal workflow names, so handle it as internal transition documentation.

**Timezone semantics:** the workflow `settings.timezone` field is **absent/empty in 130 API summaries**; 58 report `UTC`, 17 `America/Los_Angeles`, 3 `America/Chicago`, and 4 `America/New_York`. Blank means *not returned as a configured workflow timezone in this response*; do not infer UTC, the instance default, a contact timezone, or an effective schedule without separate verified configuration and runtime evidence.
