# Website AI Chatbot

Working folder for all planning, implementation, and deployment artifacts related to the website AI chatbot.

## Structure
- `plans/`: planning docs, specs, prompt drafts, rollout notes.
- `artifacts/`: exported payloads, screenshots, sample requests/responses, test captures.
- `widget/`: website embed code, JS/CSS, and UI assets.
- `n8n-workflow/`: workflow JSON, import/export files, env notes, and workflow-specific docs.
- `knowledgebase/`: approved FAQ content, document chunks, and future RAG input files.
- `scripts/`: helper scripts for deployment, data prep, or workflow packaging.
- `tests/`: chatbot test cases, transcripts, and verification notes.

## Notes
- Keep secrets out of this folder.
- Use env-driven configuration for API keys and webhook credentials.
- Treat this folder as the canonical workspace for the chatbot build.
