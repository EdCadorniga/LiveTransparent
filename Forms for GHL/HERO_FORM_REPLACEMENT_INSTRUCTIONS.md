# Hero Form Handoff (Website Admin)

Use this file as the replacement hero form:

- `Forms for GHL/hero-form-replacement.html`

What it does:
- Submits form data to  
  `https://automations.livetransparent.com/webhook/lt-form-demo-intake`
- Sends these fields:
  - `full_name`
  - `email`
  - `website`
  - `message`

Notes:
- Keep the field `name` attributes exactly as-is.
- Keep the form `action` URL exactly as-is.
- Button text is `Book a Demo.`
